# Gaza 3D GIS Lab — V2

نسخة V2 مبنية على ملف **Gaza Strip 2014** الحقيقي الذي تم تنزيله من Sketchfab.

## ما الذي تم تنفيذه؟

- تحميل نموذج `gaza_strip_2014.glb` تلقائيًا داخل الموقع.
- عرض GLB باستخدام Three.js.
- حساب عدد الـMeshes والمثلثات وأبعاد المشهد.
- تقسيم الـMesh حسب مركز كل Triangle إلى شبكة مكانية قابلة للتغيير:
  - 4×3
  - 6×5
  - 8×6
  - 12×8
- كل منطقة تصبح قابلة للنقر والتحديد بشكل مستقل.
- إظهار عدد المثلثات ونسبة المنطقة من النموذج وأبعادها المحلية.
- تركيز الكاميرا على المنطقة المحددة.
- تلوين المناطق اختياريًا.
- Wireframe اختياري.
- تصدير Metadata للمنطقة المحددة بصيغة JSON.
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.

## مهم

التقسيم الموجود في V2 هو **Spatial Pre-Segmentation هندسي** وليس نموذج AI. الهدف منه تحويل النموذج من كتلة واحدة إلى وحدات قابلة للتعامل معها قبل إضافة Semantic Segmentation لاحقًا.

الإحداثيات داخل الملف محلية وغير مسندة جغرافيًا؛ لا تعتبر WGS84 أو Palestine Grid.

## التشغيل على Windows

شغّل:

`start.bat`

ثم افتح:

`http://127.0.0.1:8080`

إذا لم يتوفر Python على الجهاز، يمكن تشغيل أي HTTP static server من مجلد المشروع.
